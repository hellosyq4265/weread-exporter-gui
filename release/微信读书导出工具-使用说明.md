# 微信读书导出工具（GUI 版）使用说明

## 快速开始

1. 双击运行 `WeReadExporterGUI.exe`。
2. 填写**书籍 ID**：在微信读书网页版（https://weread.qq.com）打开书籍详情页，
   网址末尾的一串字符就是书籍 ID；也支持含下划线的书单 ID（会导出整个书单）。
3. 勾选要导出的**格式**：Markdown、EPUB、PDF、TXT（MOBI 仅 Linux 可用，Windows 已禁用）。
4. 选择**导出位置**，导出的文件会直接保存到该文件夹。
5. 粘贴 **Cookie**，然后点击“开始导出”。

书籍 ID、导出位置和导出选项会被记住；Cookie 只在本次导出过程中使用，
不会写入 GUI 配置文件。程序不提供单独的 Cookie 验证按钮，直接开始导出即可判断登录状态。
选择 Markdown 格式时会同时生成同目录下的 `images` 文件夹，Markdown 文件中的图片引用依赖该文件夹。
如果上次导出中断，程序启动时会自动发现最近的未完成任务；保持书籍 ID 和导出位置后点击“开始导出”即可从缓存继续。
断点信息不保存 Cookie，恢复任务时仍需重新粘贴 Cookie，或勾选“强制登录（扫码）”。

界面中还可以设置**章节间隔范围（秒）**（默认 18–42）。导出时每次章节之间
都会随机等待该范围内的时长，避免固定节奏被风控识别；取消“启用随机等待”即可关闭等待。
**“单页模式（上下滚动）”** 默认开启：如果微信读书加载的是横向双栏阅读器，
程序会自动点击“上下滚动阅读”切回旧版单栏阅读器（单页显示），
避免双栏翻页导致的抓取错乱。

## 获取 Cookie

1. 用电脑浏览器登录 https://weread.qq.com；
2. 按 F12 打开开发者工具，切到 **Network（网络）** 标签；
3. 点击任意一个 `weread.qq.com` 请求，在请求头里找到 `Cookie` 字段；
4. 复制整段内容（形如 `wr_vid=xxx; wr_skey=...; ...`）粘贴到程序里。

也可以不填 Cookie，改勾选“强制登录（扫码）”，程序会弹出浏览器窗口，用微信扫码登录。
扫码登录得到的 Cookie 仅用于本次导出，不会保存到 GUI 配置；下次运行需重新粘贴 Cookie
或再次扫码登录。

## 说明与注意事项

- 程序自动使用本机已安装的 Chrome 或 Edge 浏览器，无需手动配置。
- 无头模式适合不想看到浏览器窗口的场景，但更容易被微信读书识别，建议优先使用默认模式。
- 工具通过自动化浏览器读取页面内容，仅供个人技术研究与自有书籍备份使用，
  请勿批量导出无权限的书籍，账号风险需自行承担。
- 导出前请注意目标目录中的同名文件：命令行会跳过已有目标文件，GUI 会复制生成的文件到目标目录。
- 如果导出失败，请查看 GUI 日志；常见原因是 Cookie 过期或复制不完整（缺少 `wr_vid`）。
- 随机间隔默认 18–42 秒，可在界面调整；命令行可通过
  `--min-load-interval` / `--max-load-interval` 指定，或只传 `--load-interval`
  作为基准值（程序自动按 ±40% 生成随机范围）；也可使用 `--no-random-interval` 关闭。
- 导出完成、失败或未生成文件时，GUI 会发送 Windows 通知；任务也会显示在系统托盘中。
- 命令行可通过 `--single-page` 开启单页模式（GUI 默认已开启）。
  建议保持开启：导出脚本只兼容旧版单栏阅读器，关闭后若微信读书加载
  横向双栏阅读器，导出会卡住。
- 本程序也保留了原版命令行模式，可在终端中执行：
  `WeReadExporterGUI.exe -b <书籍ID> -o epub -o pdf`

## 附：源码说明

- `gui.py`：图形界面源码，无参数启动界面，带参数时等价于原版命令行工具。
- 界面源码基于 wxPython，打包使用 PyInstaller（onefile + windowed）。
- 对原项目做了两处小改动：Windows 下自动识别 Edge；`--help` 退出码恢复正常。
